
# Dependencies

### TBB

- Download the precompiled TBB files from
https://github.com/oneapi-src/oneTBB/releases
- Copy all files into the cmake installed directory (e.g. at C:/Program Files/)

### OpenMesh, Eigen and GLFW3

- Download source codes from the official website.
- Complie them using CMake.
- Install them using CMake.

### MKL

- Download intel's MKL package from the official website.
- Run the installer of intel's MKL.
- Set environment variable 'MKLDIR=<where you install MKL>/IntelSWTools/compilers_and_libraries_xxxx/windows/mkl''

### CGAL, QT and BOOST

- Download and install accorrding to the official doc.
